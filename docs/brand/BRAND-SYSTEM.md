# Aegis Brand System

## Brand idea
Aegis is named after the mythic protective shield. The product promise is **visible protection without hidden complexity**: every important defense should be understandable, testable, and attributable to evidence rather than a decorative toggle.

## Personality
Aegis should feel calm, technical, trustworthy, precise, and modern. Avoid hacker clichés, neon overload, military language, skulls, lock-wallpaper imagery, or fear-based warnings.

## Logo
The primary mark is a geometric shield containing an A-shaped negative space. The center dot represents a protected identity/core. Use `assets/brand/aegis-mark.svg` for app icons and `assets/brand/aegis-wordmark.svg` for product/README branding.

## Colors
- Aegis Ink: `#07131B` — primary dark background.
- Sentinel Navy: `#0D202C` — surfaces and panels.
- Aegis Mint: `#62E6C3` — safe/protected/primary action.
- Signal Blue: `#6F9EFF` — secondary action, verification, identity controls.
- Clear White: `#EEF9FB` — primary text.
- Muted Steel: `#8EABB4` — secondary text.
- Warning Amber: `#F4C66D` — caution.
- Critical Rose: `#FF7589` — destructive action or failed verification.

## Typography
Use the platform system stack so the browser does not require remote font downloads. Default UI copy should render at 14–15 px or larger; secondary explanatory copy should not fall below 11 px. Security evidence and permission dialogs prioritize legibility over density.

## Iconography
Use simple geometric line/filled icons with a 2 px visual stroke and rounded corners. Status color is supplemental only; PASS/FAIL/NOT TESTED text must remain visible for accessibility.

## Voice
Short, factual, and evidence based. Prefer “Blocked 7 tracker requests” over “You are completely safe.” Prefer “Not tested” over implying a defense is active without proof.
