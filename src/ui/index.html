Permission defaults

Aegis blocks powerful APIs by default. Use Ask only when needed; trusted-site exceptions are safer than weakening global defaults.

Network routing

Route each isolated tab session directly or through a proxy. Aegis never silently starts a proxy service.

Sets SOCKS5 to 127.0.0.1:9050. A local Tor service must already be running.
Leak resistanceAegis forces Chromium’s WebRTC IP handling policy to disable non-proxied UDP. Proxy changes close existing session connections before subsequent requests.

Anonymous compartment

Tails/Qubes-inspired fail-closed browsing. Aegis requires a locally running Tor SOCKS proxy, verifies the route with the Tor Project before browsing, blocks local-network targets, disables extensions, blocks downloads, removes WebRTC, and uses the Maximum fingerprint profile.

Open anonymous compartment

Creates a fresh memory-only tab. If Tor verification fails, the tab refuses to browse.

Tor is not bundledA local Tor service must already be running. Aegis does not claim Tor Browser-equivalent anonymity on the Electron engine.
